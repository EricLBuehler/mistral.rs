## Features

<CardGrid>
  <Card title="Auto-detection" icon="rocket">
    `mistralrs run -m <model>` works without flags. The binary infers the
    architecture and chat template from the Hugging Face repository, and
    selects the accelerator from the detected hardware.
    [Quickstart](/quickstart/)
  </Card>
  <Card title="Quantization" icon="puzzle">
    For a GGUF repository, `--quant` selects a matching artifact. For other
    Hugging Face repositories, it loads a prebuilt
    [UQFF](/reference/uqff-format/) when available and otherwise
    applies in-situ quantization.
    [Quantization guide](/guides/quantization/quantize-a-model/)
  </Card>
  <Card title="Tuning and diagnostics" icon="seti:config">
    `mistralrs tune` recommends quantization and device mapping from the model
    config and detected hardware, without loading the model. `mistralrs doctor`
    checks hardware, build features, and Hugging Face connectivity.
    [CLI reference](/reference/cli/)
  </Card>
  <Card title="Agents" icon="open-book">
    Local agent runtime with a server-side tool loop, file inputs, web search, code
    execution, shell, OpenAI-compatible Skills, MCP, generated media, and sessions.
    [Agents & tools](/guides/agents/)
  </Card>
  <Card title="Multi-GPU" icon="seti:hex">
    Scale a model across GPUs and nodes: NCCL tensor parallelism, layer/P2P
    device mapping, multi-node NCCL, and the ring backend.
    [Distributed inference](/guides/perf/distributed-inference/)
  </Card>
  <Card title="Web UI" icon="laptop">
    Browser chat with reasoning blocks, tool, code, and shell call
    visualization, and inline search results.
    [Web UI](/guides/serve/with-web-ui/)
  </Card>
</CardGrid>
