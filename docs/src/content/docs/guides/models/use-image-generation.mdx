## Running FLUX

```bash
mistralrs serve -m black-forest-labs/FLUX.1-schnell
```

For gated checkpoints such as FLUX.1-dev, accept the Hugging Face license and run `mistralrs login` first.

The CLI loads the fully resident `Flux` pipeline. If it does not fit, the native SDKs expose `FluxOffloaded`, which moves components to CPU at a speed cost. Diffusion models do not support ISQ; omit `--quant` and `--isq`.

<TabItem label="HTTP">

```bash
curl http://localhost:1234/v1/images/generations \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "default",
    "prompt": "A golden retriever wearing a scarf in autumn leaves.",
    "height": 1024,
    "width": 1024,
    "response_format": "B64Json"
  }'
```

</TabItem>
<TabItem label="Python">

```python
from mistralrs import DiffusionArchitecture, ImageGenerationResponseFormat, Runner, Which

runner = Runner(which=Which.DiffusionPlain(
    model_id="black-forest-labs/FLUX.1-schnell",
    arch=DiffusionArchitecture.FluxOffloaded,
))
response = runner.generate_image(
    "A vibrant sunset in the mountains.", ImageGenerationResponseFormat.B64Json,
)
```

</TabItem>
<TabItem label="Rust">

```rust
use mistralrs::{DiffusionGenerationParams, DiffusionLoaderType,
    DiffusionModelBuilder, ImageGenerationResponseFormat};

let model = DiffusionModelBuilder::new(
    "black-forest-labs/FLUX.1-schnell", DiffusionLoaderType::FluxOffloaded,
).build().await?;
let response = model.generate_image(
    "A vibrant sunset in the mountains.".to_string(),
    ImageGenerationResponseFormat::B64Json,
    DiffusionGenerationParams::default(), None,
).await?;
```

## Request fields

| Field | Default | Meaning |
| --- | --- | --- |
| `prompt` | Required | Image description |
| `n` | 1 | Image count |
| `height` / `width` | 720 / 1280 | Pixels; the OpenAI `size` string is unsupported |
| `response_format` | `Url` | `Url` returns a server-side filename; `B64Json` returns an inline PNG data URL |

## Memory notes

FLUX includes a large diffusion model and text encoders. Quantization flags do not reduce its footprint; use `FluxOffloaded` from an SDK when full residency is impractical.

## Output handling

For remote clients, use `B64Json` and strip the data-URL prefix before decoding:

```python
import base64

payload = response.data[0].b64_json.split(",", 1)[1]
with open("out.png", "wb") as output:
    output.write(base64.b64decode(payload))
```

`Url` refers to a file on the server, not an automatically hosted download URL. Read or copy it only from a process with access to that filesystem.
