read 18 * 256 * 4 = 18432 bytes = 128 * sizeof(block_q8_1_mmq).
This is the full 128-column tile_y read in mul_mat_q_process_tile.

The VMM pool maps physical backing allocations in granularity-sized chunks;
the reported 4 MiB allocation is that backing allocation, not the logical
src1_q8_1 request. The final partial expert tile can run past the compact
activation buffer. Existing padding uses ne11, which is 1 for broadcast
gate/up or the selected-expert count for down, despite the J=128 kernel.

The isolated patch reserves 128 activation blocks after the logical buffer,
128 IDs after ids_dst, and 128 optional NVFP4 scales. The maximum dispatched
J in mul_mat_q_switch_J is 128. No kernel, routing, arithmetic, tile choice,
or quantization code is changed. Only mmq.cu is recompiled; all 143 other
CUDA object files and all other shared libraries are reused unchanged.
